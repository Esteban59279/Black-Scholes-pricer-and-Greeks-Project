# Black-Scholes-pricer-and-Greeks-Project
This script analytically calculates the price of call (Call) and put (Put) options using the Black-Scholes formula. The code is based on the numpy, scipy.stats, and vollib libraries. It incorporates dedicated functions to calculate Delta, Gamma, Vega, Theta, and Rho from defined parameters (r, S, K , T, volatility).
